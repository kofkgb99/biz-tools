1. 기준 파일 거래조건 · 비용배부분류 · 제품분류 · 기준정보

머리글: 채널 · 일자 · 제품코드 · 제품명 · 카테고리명 · 전환유형명 · EDI수량 · 전환수량 · 매입금액
일자별 가로형(“01일 납품금액” 열) 원본도 읽어요.

3. 기간 설정

월 고정금액은 경과일 ÷ 월일수로 일할한 뒤 매입비중으로 배분해요. 경과일은 채널별 마지막 일자로 자동 설정 (수정 가능).
기준 파일과 매입 로우를 올리면 여기에 결과가 나와요.
계산 결과가 없어요.
○ 기준 파일 「거래조건」 위에 화면에서 조건을 더하거나 끌 수 있어요 (엑셀은 그대로)
○ 바뀐 조건은 바로 재계산되고, 이 브라우저에 저장돼요
[1. 채널별 계산 규칙]
물류비 대상: 직납만 = 전환유형명 “직납-전환대상아님” 행만 / 전체 = 모든 행. 과세 ×1.1 = 면과세가 “과세”인 제품의 물류비·우유 장려금율에 1.1 곱함. 카테고리명 대체 = 판관비분류로 율이 없으면 로우 카테고리명으로 찾음.
[2. 추가 계약조건]
기준: 매입금액 % · 매출(출고가) % = 해당 행 금액 × 율 / 월 고정금액 = 금액 × 경과일 ÷ 월일수, 대상 안에서 매입비중으로 배분. 대상을 비우면 그 채널 전체. 채널을 비우면 전 채널 공통.
예) 쿠팡 계약비용 25% → 39% : 「판관비 · 매입금액 % · 14%」 한 줄 추가 (기존 25%는 거래조건에 그대로)
[3. 거래조건 항목 끄기] 기준 파일에서 읽은 항목 중 계산에서 뺄 것
출고가 · 변동원가 · 운송비 = 기준정보 / 율 · 금액 = 거래조건 + 추가 계약조건
